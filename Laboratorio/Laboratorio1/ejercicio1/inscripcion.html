1.Informacion general

Contenido del taller

  • Estructura semantica con HTML5
  • Hojas de estilo en cascada (CSS)
  • Maquetacion con Flexbox y CSS Grid
  • Formularios y validacion en el cliente

Requisitos previos (en orden)

  1. Tener aprobada la materia Programacion I
  2. Contar con un editor de codigo instalado
  3. Presentar el Laboratorio 1 concluido
  4. Realizar el pago de matricula

Glosario basico

HTML
Lenguaje de marcado que define la estructura del contenido.
CSS
Lenguaje de estilo que define la presentacion visual.
Responsive
Diseno que se adapta al tamano de cualquier dispositivo.
